Limits, Continuity & L'Hôpital's Rule

$$\lim_{x \to 0} \frac{\sin(x)}{x} = 1 \quad \text{and} \quad \lim_{x \to 0} \frac{1 - \cos(x)}{x} = 0$$
$$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e \quad \text{and} \quad \lim_{x \to 0} (1 + x)^{1/x} = e$$
$$\text{L'Hôpital's Rule: If } \lim \frac{f(x)}{g(x)} = \frac{0}{0} \text{ or } \frac{\pm\infty}{\pm\infty}, \text{ then } \lim \frac{f(x)}{g(x)} = \lim \frac{f'(x)}{g'(x)}$$
$$\text{Definition of Continuity: } f(x) \text{ is continuous at } x = c \iff \lim_{x \to c} f(x) = f(c)$$
$$\text{Intermediate Value Theorem (IVT): If } f \text{ is continuous on } [a,b], \text{ then } f takes all values between } f(a) \text{ and } f(b).$$

Advanced Integration Techniques & Reduction

$$\int u \, dv = uv - \int v \, du \quad \text{(Integration by Parts)}$$
$$\int \sin^n(x) \, dx = -\frac{\sin^{n-1}(x)\cos(x)}{n} + \frac{n-1}{n}\int \sin^{n-2}(x) \, dx$$
$$\int \cos^n(x) \, dx = \frac{\cos^{n-1}(x)\sin(x)}{n} + \frac{n-1}{n}\int \cos^{n-2}(x) \, dx$$
$$\int \frac{dx}{\sqrt{a^2 - x^2}} = \arcsin\left(\frac{x}{a}\right) + C \quad \left[\text{Sub: } x = a\sin(\theta)\right]$$
$$\int \frac{dx}{a^2 + x^2} = \frac{1}{a} \arctan\left(\frac{x}{a}\right) + C \quad \left[\text{Sub: } x = a\tan(\theta)\right]$$
$$\int \frac{dx}{\sqrt{x^2 - a^2}} = \text{arcosh}\left(\frac{x}{a}\right) + C \quad \left[\text{Sub: } x = a\sec(\theta)\right]$$

Extremes, Optimization & Mean Value Theorem Applications

$$\text{Critical Points: Values } c \text{ in domain where } f'(c) = 0 \text{ or } f'(c) \text{ is undefined.}$$
$$\text{First Derivative Test: If } f'(x) \text{ changes from }+ \text{ to } - \text{ at } c \implies \text{Local Max at } c.$$
$$\text{Second Derivative Test: If } f'(c) = 0 \text{ and } f''(c) < 0 \implies \text{Local Max at } c.$$
$$\text{Mean Value Theorem (MVT): If continuous on } [a,b] \text{ and differentiable on } (a,b), \text{ then } f'(c) = \frac{f(b)-f(a)}{b-a}$$
$$\text{Arc Length Formula: } L = \int_{a}^{b} \sqrt{1 + [f'(x)]^2} \, dx$$
$$\text{Volume by Washer/Disk: } V = \pi \int_{a}^{b} \left([R(x)]^2 - [r(x)]^2\right) dx$$

Sequences, Series & Taylor/Maclaurin Expansions

$$\sum_{n=0}^{\infty} ar^n = \frac{a}{1 - r} \quad (\lvert r \rvert < 1) \quad \text{(Geometric Series)}$$
$$\text{Taylor Series: } f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!} (x - a)^n$$
$$e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \dots \quad (\text{Maclaurin for } e^x)$$
$$\sin(x) = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$$
$$\cos(x) = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots$$
$$\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \dots \quad (\lvert x \rvert < 1)$$

Multivariable Calculus & Vector Theorems

$$\text{Gradient: } \nabla f = \left\langle \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right\rangle$$
$$\text{Divergence: } \nabla \cdot \mathbf{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}$$
$$\text{Curl: } \nabla \times \mathbf{F} = \left(\frac{\partial R}{\partial y} - \frac{\partial Q}{\partial z}\right)\mathbf{i} - \left(\frac{\partial R}{\partial x} - \frac{\partial P}{\partial z}\right)\mathbf{j} + \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)\mathbf{k}$$
$$\text{Green's Theorem: } \oint_C (L \, dx + M \, dy) = \iint_D \left(\frac{\partial M}{\partial x} - \frac{\partial L}{\partial y}\right) dA$$
$$\text{Divergence Theorem: } \iint_S \mathbf{F} \cdot d\mathbf{S} = \iiint_V (\nabla \cdot \mathbf{F}) dV$$
$$\text{Stokes' Theorem: } \oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_S (\nabla \times \mathbf{F}) \cdot d\mathbf{S}$$
